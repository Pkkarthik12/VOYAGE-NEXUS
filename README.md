# VOYAGE-NEXUS
# Voyage Nexus Web Project
# This document provides an overview of the "Voyage Nexus" web development project based on the provided source files.
# The project is a multi-page travel agency website designed to showcase premier global destinations and facilitate trip bookings.
# Project OverviewVoyage Nexus is a futuristic travel agency specializing in personalized global journeys. The website provides information on iconic cities, agency background, customer testimonials, and a functional booking interface.
##File Structure
# The project consists of several interconnected HTML files, CSS stylesheets, and assets
# index.html-The landing page featuring a hero section and a gallery of premier destinations (Paris, Tokyo, New York, Dubai, Sydney).
# About us.html-Detailed information about the agency's history, mission, and professional experience.
# Paris.html-Destination page for Paris, highlighting the Eiffel Tower, Louvre, and French cuisine. 
# Tokyo.htmL-Destination page for Tokyo, showcasing Senso-ji Temple, Akihabara, and Tsukiji Market. 
# New york.html-Destination page for New York, featuring the Empire State Building, Broadway, and Central Park. 
# Dubai.html-Destination page for Dubai, focusing on opulence and the Burj Khalifa.
# Syndey.html-Destination page for Sydney, highlighting harbor views and beaches.
# Booking.html-A functional booking form for users to confirm their travel details.
# Style.css-The primary external stylesheet used to maintain a consistent visual theme.
