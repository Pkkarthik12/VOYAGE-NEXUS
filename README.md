# Voyage Nexus ✈️
**A Futuristic Multi-Page Travel Experience**

Voyage Nexus is a modern web project for a luxury travel agency, focusing on high-impact visuals and a seamless user journey across global destinations.

## 📁 Project Structure
The repository is organized into interconnected modules for easy navigation and maintenance:

* **`index.html`** – Hero landing page with destination gallery.
* **`About us.html`** – Mission statement and agency background.
* **`Booking.html`** – Interactive form for travel reservations.
* **`Style.css`** – Global stylesheet for a unified, professional aesthetic.
* **Destination Pages** – Dedicated modules for Paris, Tokyo, New York, Dubai, and Sydney.

## ✨ Key Features
* **Minimalist UI:** Clean, professional design with a focus on typography.
* **Multi-Page Architecture:** Logic-based routing between different global cities.
* **Responsive Layouts:** Designed to scale across desktop and mobile browsers.
* **Functional Booking:** Structured input handling for user travel data.

## 🛠️ Tech Stack
* **HTML5** – Semantic structure.
* **CSS3** – Custom Grid/Flexbox layouts and styling.
